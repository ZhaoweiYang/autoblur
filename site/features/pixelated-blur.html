Why mosaic

When soft blur isn't enough

Gaussian blur looks natural but keeps some structure. Mosaic and pixelation destroy it — which is what a compliance deliverable usually needs.

Hard to reverse

Averaging each block throws the detail away, so the covered region cannot be reconstructed from the export.

Block size you choose

Fine pixelation keeps the shape readable; chunky mosaic removes it entirely. Both are one slider away.

Broad format support

MP4, MOV, M4V, AVI and MKV in, with preview and HD export out.

Step-by-step face pixelation

Detected faces can be pixelated one by one, so you decide exactly who is covered.

Images too

The same mosaic runs on stills — useful for screenshots, documents and listing photos.

Rendered into the file

The mosaic is baked into the exported pixels rather than laid over them, so there is no overlay to remove.

FAQ

Common questions

Do I need a desktop editor to pixelate a video?

No. You do not need a desktop timeline editor for common pixelated blur tasks — step-by-step face pixelation is available in your browser.

Which video formats can I upload?

MP4, MOV, M4V, AVI and MKV are supported, with preview and HD export.

Is mosaic safer than blur?

For anonymisation, yes. Mosaic and pixelation discard the detail inside each block, while a light gaussian blur can leave recoverable structure.

Can I pixelate only one face in a group?

Yes. Each detected face is listed separately, so you pick exactly which ones get covered.

Does the export lose quality?

Only the pixelated regions change. Everything else is re-encoded at HD quality.
